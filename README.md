# 🍽️ Flavoria Restaurant Website

A modern, fully responsive restaurant website designed to provide a seamless user experience. 

## ✨ Features
* 📱 **Fully Responsive:** Looks great on desktops, tablets, and mobile devices.
* 📜 **Interactive Menu:** Browse categories and view delicious food offerings easily.
* 📅 **Online Table Reservation:** Convenient table booking system for customers.
* 🎨 **Sleek UI & Animations:** Smooth transitions and elegant presentation built with raw web standards.

## 🛠️ Tech Stack
* **HTML5**
* **CSS3**
* **JavaScript (JS)**
